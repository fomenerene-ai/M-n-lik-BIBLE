# Parley

Personal English speaking and listening trainer for an Android tablet (installable PWA).
Full documentation arrives with milestone M10. See `CLAUDE.md` for the fixed decisions and structure.

Run locally: `python3 -m http.server 8080` from the repo root, then open `http://localhost:8080/parley/`.
Tests: `node --test "parley/tests/*.test.js"`.
