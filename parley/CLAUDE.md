# Parley: working notes for Claude sessions

Parley is a personal English speaking and listening trainer (PWA) for one French-speaking B1-B2 learner.
It lives in `parley/` inside the Ménélik Bible repository. The Bible app at the repo root is a separate
Vite project: never touch it except the two shared integration points listed below.

## Fixed decisions (do not revisit)

- Android tablet, Chrome, landscape only. Reference 1280x800, must work from 1024 to 1920 px wide.
- Always online. The service worker caches the app shell only.
- Static PWA on GitHub Pages, served from `<repo>/parley/`. All paths relative. No build step, no bundler,
  no framework, no runtime dependencies. Google Fonts (Fredoka, Nunito) are the only external assets.
- UI in English only. No French string in the UI. Light theme only, design direction "A, Pop".
- App name comes from `APP_NAME` in `src/config.js` (default "Parley"). Never hard-code it elsewhere
  in JS. `index.html`, `manifest.webmanifest` and README repeat it as static text: rename them too.
- Conversation engine: Anthropic Messages API called from the browser with the user's own key
  (header `anthropic-dangerous-direct-browser-access: true`). Key stored in IndexedDB only, never in the
  repo, exports, logs, URLs or error messages. Default model `claude-sonnet-5-5`, editable.
- TTS: `speechSynthesis`. STT: `webkitSpeechRecognition`. No paid voice API.
- Audio always at natural speed. Replay, sentence repeat and A-B loop allowed. No slow-down.
- Corrections only in the end-of-conversation report. Never interrupt the learner.
- Gamification: XP and levels only. No streaks, badges, reminders or notifications.
- Statistics: minutes practised per day only (7 and 30 days).
- Microphone audio is analysed in memory and discarded. Never persisted.
- New cards unlimited. Due reviews always before new cards.
- Data local only (IndexedDB), with JSON export and import. Imported audio blobs are not exported.

## Structure

```
parley/
  index.html, manifest.webmanifest, sw.js
  assets/icons/        icons generated by tools/make-icons.mjs
  styles/              tokens.css (design tokens), base.css, components.css, screens.css
  src/config.js        APP_NAME, defaults, level tables, plan
  src/main.js          bootstrap; src/router.js hash router
  src/state/           IndexedDB wrapper (db.js) and stores (settings, profile, minutes, sessions, cards,
                       reports, content, shadow attempts), activity tracker, backup
  src/ai/              claude.js (fetch client, SSE), prompts.js (all prompts), schema.js (JSON validation)
  src/speech/          tts.js, stt.js
  src/audio/           pitch.js (YIN), dtw.js, segment.js, rhythm.js, capture.js, library.js
  src/learning/        pure logic: srs, diff, xp, adaptive, text, transcript, placement bank, shadow tiers
  src/content/         content pool across tiers 0 to 3
  src/screens/         one module per screen: export render(root, params, ctx) returning cleanup
  src/ui/              dom.js (h() helper, textContent only), components.js, icons.js, toast.js
  content/voa-manifest.json
  tools/               node scripts: icons, manifest validation, secret scan, sw precache list
  tests/               node --test, no dependencies
  docs/                DECISIONS.md, MANUAL-TESTS.md
```

## Conventions

- ES modules, JSDoc on exported functions. Pure logic never touches DOM or IndexedDB at import time, so
  `node --test "parley/tests/*.test.js"` can import it.
- Render AI output, imported files and user text with `textContent` only. Never `innerHTML`.
  `h()` in `src/ui/dom.js` is the only element factory.
- No inline `style` attributes in HTML (CSP has no 'unsafe-inline'); set dynamic sizes through
  `el.style.x = ...` in JS.
- Every icon is an inline SVG from `src/ui/icons.js` (24 px, stroke 2.2, round caps). No emoji.
- localStorage only for trivial UI flags, keys prefixed `parley.`. Cache names prefixed `parley-`.
- IndexedDB name `parley` (independent of APP_NAME so a rename keeps data).
- All system prompts live in `src/ai/prompts.js`.
- After changing any file in the app shell, run `node parley/tools/build-sw.mjs` to refresh the precache
  list and version in `sw.js` (a test fails otherwise).
- Before committing: `node --test "parley/tests/*.test.js"` and `node parley/tools/check-secrets.mjs`.
- One line per non-obvious decision in `docs/DECISIONS.md`.

## Shared integration points with the Bible app

1. `.github/workflows/deploy.yml` and `tests.yml`: run Parley tests and copy `parley/` into `dist/parley`.
2. `src/sw-template.js` (Bible service worker): ignores requests under `./parley/` so both apps coexist.
