# Test manuel : projection en visioconférence

À réaliser sur la tablette réelle, application **installée** (pas dans un onglet Chrome).

## Préparation

- Android 14 ou plus, Ménélik Bible installée et prête hors ligne.
- Un second appareil (téléphone ou ordinateur) connecté à la même réunion, pour voir ce que voient
  les participants.
- File de projection préparée : par exemple `Jean 3:16-21` et `Psaumes 23`.

## Google Meet

1. Rejoindre la réunion depuis la tablette.
2. **Partager l’écran**. Si Android propose « Partager une application » : choisir **Ménélik Bible**.
3. Revenir dans Ménélik Bible, ouvrir **Projection**, toucher **Projeter**.
4. Sur le second appareil, vérifier :
   - [ ] seule la diapositive est visible (fond noir, texte jaune) ;
   - [ ] aucune notification, barre d’état ni autre application n’apparaît ;
   - [ ] balayage gauche/droite : la diapositive change ;
   - [ ] double appui : écran noir, puis retour ;
   - [ ] balayage haut/bas : la taille change et le texte tient toujours.
5. Appui long : quitter. Vérifier ce que voient les participants à ce moment.

## Zoom

Même procédure : **Partager › Écran**, puis, si proposé, l’application seule.

## Solution de repli

Si seul le partage de l’écran entier est proposé :

1. Activer **Ne pas déranger** avant la séance (tirer le volet des réglages rapides) pour masquer
   les notifications.
2. Ouvrir la projection **avant** de lancer le partage, et arrêter le partage **avant** de quitter
   la projection (appui long), pour que les participants ne voient jamais l’écran de contrôle.
3. Utiliser le double appui (écran noir) pour masquer l’écran pendant un changement.
